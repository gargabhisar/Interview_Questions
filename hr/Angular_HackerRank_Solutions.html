Load Grid from API (Pagination + Observable)

Build a C# ASP.NET Core Web API that returns paginated employee data, then consume it in Angular with HttpClient, an Observable, and a paginated HTML grid/table.

Architecture

  • Backend: GET /api/employees?pageNumber=1&pageSize=10 returns JSON with items, totalCount, pageNumber, pageSize, totalPages
  • Frontend: Service exposes Observable<PagedResult<Employee>> → component subscribes → template binds grid rows + pagination buttons

Key Concepts

  • Observable — async stream from HTTP; subscribe in component or use async pipe in template
  • HttpClient.get<T>() — typed GET request; import HttpClientModule
  • Server-side pagination — API slices data; grid reloads on page change (preferred in interviews)
  • CORS — enable in Program.cs so Angular (port 4200) can call API (port 5000/7000)
Interview Tip: Mention why server-side pagination scales better than loading all rows client-side. Always handle loading and empty states. Unsubscribe or use takeUntilDestroyed() if the component can be destroyed mid-request.

public class PagedResult<T>
{
    public List<T> Items { get; set; } = new();
    public int TotalCount { get; set; }
    public int PageNumber { get; set; }
    public int PageSize { get; set; }
    public int TotalPages { get; set; }

Controllers/EmployeesController.cs 
using Microsoft.AspNetCore.Mvc;
using EmployeeApi.Models;

namespace EmployeeApi.Controllers;

[ApiController]
[Route("api/[controller]")]
public class EmployeesController : ControllerBase
{
    private static readonly List<Employee> _employees = Enumerable
        .Range(1, 47)
        .Select(i => new Employee
        {
            Id = i,
            Name = $"Employee {i}",
            Department = i % 2 == 0 ? "Engineering" : "Sales",
            Email = $"emp{i}@company.com"
        })
        .ToList();

    [HttpGet]
    public ActionResult<PagedResult<Employee>> GetEmployees(
        [FromQuery] int pageNumber = 1,
        [FromQuery] int pageSize = 10)
    {
        if (pageNumber < 1) pageNumber = 1;
        if (pageSize < 1) pageSize = 10;

        var totalCount = _employees.Count;
        var items = _employees
            .Skip((pageNumber - 1) * pageSize)
            .Take(pageSize)
            .ToList();

        return Ok(new PagedResult<Employee>
        {
            Items = items,
            TotalCount = totalCount,
            PageNumber = pageNumber,
            PageSize = pageSize,
            TotalPages = (int)Math.Ceiling(totalCount / (double)pageSize)
        });
    }
}

services/employee.service.ts 
import { Injectable } from '@angular/core';
import { HttpClient, HttpParams } from '@angular/common/http';
import { Observable } from 'rxjs';
import { Employee, PagedResult } from '../models/employee.model';

@Injectable({ providedIn: 'root' })
export class EmployeeService {
  private readonly apiUrl = 'https://localhost:7000/api/employees';

  constructor(private http: HttpClient) {}

  getEmployees(pageNumber: number, pageSize: number): Observable<PagedResult<Employee>> {
    const params = new HttpParams()
      .set('pageNumber', pageNumber)
      .set('pageSize', pageSize);

    return this.http.get<PagedResult<Employee>>(this.apiUrl, { params });
  }
}
app.component.ts 
import { Component, OnInit } from '@angular/core';
import { EmployeeService } from './services/employee.service';
import { Employee, PagedResult } from './models/employee.model';

@Component({
  selector: 'app-root',
  templateUrl: './app.component.html'
})
export class AppComponent implements OnInit {
  employees: Employee[] = [];
  currentPage = 1;
  pageSize = 10;
  totalPages = 1;
  totalCount = 0;
  loading = false;
  error = '';

  constructor(private employeeService: EmployeeService) {}

  ngOnInit(): void {
    this.loadGrid();
  }

  loadGrid(): void {
    this.loading = true;
    this.error = '';

    this.employeeService.getEmployees(this.currentPage, this.pageSize)
      .subscribe({
        next: (result: PagedResult<Employee>) => {
          this.employees = result.items;
          this.currentPage = result.pageNumber;
          this.pageSize = result.pageSize;
          this.totalPages = result.totalPages;
          this.totalCount = result.totalCount;
          this.loading = false;
        },
        error: () => {
          this.error = 'Failed to load employees.';
          this.loading = false;
        }
      });
  }

  prevPage(): void {
    if (this.currentPage > 1) {
      this.currentPage--;
      this.loadGrid();
    }
  }

  nextPage(): void {
    if (this.currentPage < this.totalPages) {
      this.currentPage++;
      this.loadGrid();
    }
  }
}

1. Temperature Converter

Build a real-time °C ↔ °F converter. Typing in one field instantly updates the other using two-way binding and conversion formulas.

Key Concepts

  • [(ngModel)] for two-way data binding (requires FormsModule)
  • Conversion: F = C × 9/5 + 32 and C = (F − 32) × 5/9
  • Use a flag to prevent infinite update loops when both fields sync each other
HackerRank Tip: Only edit the files they allow (usually app.component.ts and app.component.html). Import FormsModule in the module if ngModel throws an error.
app.component.ts 
import { Component } from '@angular/core';

@Component({
  selector: 'app-root',
  templateUrl: './app.component.html',
  styleUrls: ['./app.component.css']
})
export class AppComponent {
  celsius: number | null = null;
  fahrenheit: number | null = null;
  private updating = false;

  onCelsiusChange(): void {
    if (this.updating) return;
    this.updating = true;
    this.fahrenheit = this.celsius != null
      ? +(this.celsius * 9 / 5 + 32).toFixed(2)
      : null;
    this.updating = false;
  }

  onFahrenheitChange(): void {
    if (this.updating) return;
    this.updating = true;
    this.celsius = this.fahrenheit != null
      ? +((this.fahrenheit - 32) * 5 / 9).toFixed(2)
      : null;
    this.updating = false;
  }
}

  </label>

  • Subscribe to Observable or use async pipe

weather.service.ts 
import { Injectable } from '@angular/core';
import { HttpClient } from '@angular/common/http';
import { Observable } from 'rxjs';

export interface WeatherData {
  city: string;
  temperature: number;
  humidity: number;
  windSpeed: number;
}

@Injectable({ providedIn: 'root' })
export class WeatherService {
  constructor(private http: HttpClient) {}

  getWeather(city: string): Observable<WeatherData> {
    return this.http.get<WeatherData>(
      `https://api.example.com/weather?city=${encodeURIComponent(city)}`
    );
  }
}
app.component.ts 
import { Component } from '@angular/core';
import { WeatherService, WeatherData } from './weather.service';

@Component({
  selector: 'app-root',
  templateUrl: './app.component.html'
})
export class AppComponent {
  city = '';
  weather: WeatherData | null = null;
  notFound = false;
  loading = false;

  constructor(private weatherService: WeatherService) {}

    if (!this.city.trim()) return;
    this.loading = true;

      next: (data) => {
        this.weather = data;
        this.loading = false;
      },
      error: () => {
        this.notFound = true;
        this.loading = false;
      }
    });
  }
}

6. Kanban Board Slider

Manage cards across columns (Backlog → To-Do → In-Progress → Done). Move cards left/right; disable buttons at column boundaries.

app.component.ts 
import { Component } from '@angular/core';

interface Card {
  id: number;
  title: string;
}

@Component({
  selector: 'app-root',
  templateUrl: './app.component.html'
})
export class AppComponent {
  columns: Card[][] = [
    [{ id: 1, title: 'Setup project' }],
    [{ id: 2, title: 'Write tests' }],
    [],
    []
  ];

  columnNames = ['Backlog', 'To-Do', 'In-Progress', 'Done'];

  moveRight(colIndex: number, cardIndex: number): void {
    if (colIndex < this.columns.length - 1) {
      const card = this.columns[colIndex].splice(cardIndex, 1)[0];
      this.columns[colIndex + 1].push(card);
    }
  }

  moveLeft(colIndex: number, cardIndex: number): void {
    if (colIndex > 0) {
      const card = this.columns[colIndex].splice(cardIndex, 1)[0];
      this.columns[colIndex - 1].push(card);
    }
  }

  canMoveLeft(colIndex: number): boolean  { return colIndex > 0; }
  canMoveRight(colIndex: number): boolean { return colIndex < this.columns.length - 1; }

  addCard(colIndex: number, title: string): void {
    if (title.trim()) {
      this.columns[colIndex].push({
        id: Date.now(),
        title: title.trim()
      });
    }
  }
}
app.component.html 
<div class="board">
  <div *ngFor="let column of columns; let colIndex = index" class="column">
    <h3>{{ columnNames[colIndex] }}</h3>

    <div *ngFor="let card of column; let cardIndex = index" class="card">
      <p>{{ card.title }}</p>
      <button (click)="moveLeft(colIndex, cardIndex)"
              [disabled]="!canMoveLeft(colIndex)">←</button>
      <button (click)="moveRight(colIndex, cardIndex)"
              [disabled]="!canMoveRight(colIndex)">→</button>
    </div>
  </div>
</div>
HackerRank Tip: Use [disabled] binding — not *ngIf hiding buttons unless the template requires it. After splice, Angular change detection updates the view automatically.

7. Survey List / Paginated Table

Fetch customer records, render a paginated table, and filter/search dynamically.

survey.service.ts 
import { Injectable } from '@angular/core';
import { HttpClient } from '@angular/common/http';
import { Observable } from 'rxjs';

export interface SurveyRecord {
  id: number;
  name: string;
  email: string;
  rating: number;
}

@Injectable({ providedIn: 'root' })
export class SurveyService {
  constructor(private http: HttpClient) {}

  getRecords(): Observable<SurveyRecord[]> {
    return this.http.get<SurveyRecord[]>('/api/surveys');
  }
}
app.component.ts 
import { Component, OnInit } from '@angular/core';
import { SurveyService, SurveyRecord } from './survey.service';

@Component({
  selector: 'app-root',
  templateUrl: './app.component.html'
})
export class AppComponent implements OnInit {
  allRecords: SurveyRecord[] = [];
  filteredRecords: SurveyRecord[] = [];
  searchTerm = '';
  currentPage = 1;
  pageSize = 5;

  constructor(private surveyService: SurveyService) {}

  ngOnInit(): void {
    this.surveyService.getRecords().subscribe(data => {
      this.allRecords = data;
      this.applyFilter();
    });
  }

  applyFilter(): void {
    const term = this.searchTerm.toLowerCase();
    this.filteredRecords = this.allRecords.filter(r =>
      r.name.toLowerCase().includes(term) ||
      r.email.toLowerCase().includes(term)
    );
    this.currentPage = 1;
  }

  get paginatedRecords(): SurveyRecord[] {
    const start = (this.currentPage - 1) * this.pageSize;
    return this.filteredRecords.slice(start, start + this.pageSize);
  }

  get totalPages(): number {
    return Math.ceil(this.filteredRecords.length / this.pageSize) || 1;
  }

  prevPage(): void {
    if (this.currentPage > 1) this.currentPage--;
  }

  nextPage(): void {
    if (this.currentPage < this.totalPages) this.currentPage++;
  }
}
app.component.html 
<input [(ngModel)]="searchTerm"
       (ngModelChange)="applyFilter()"
       placeholder="Search by name or email" />

<table>
  <thead>
    <tr><th>ID</th><th>Name</th><th>Email</th><th>Rating</th></tr>
  </thead>
  <tbody>
    <tr *ngFor="let record of paginatedRecords">
      <td>{{ record.id }}</td>
      <td>{{ record.name }}</td>
      <td>{{ record.email }}</td>
      <td>{{ record.rating }}</td>
    </tr>
    <tr *ngIf="paginatedRecords.length === 0">
      <td colspan="4">No records found.</td>
    </tr>
  </tbody>
</table>

<button (click)="prevPage()" [disabled]="currentPage === 1">Previous</button>
<span>Page {{ currentPage }} of {{ totalPages }}</span>
<button (click)="nextPage()" [disabled]="currentPage === totalPages">Next</button>

3. Reactive Forms (FormGroup + FormControl)

Form structure is defined in the component class. Preferred for interviews and production apps.

reactive-form.component.ts 
import { Component, OnInit } from '@angular/core';
import { FormBuilder, FormGroup, Validators } from '@angular/forms';

@Component({
  selector: 'app-reactive-form',
  templateUrl: './reactive-form.component.html'
})
export class ReactiveFormComponent implements OnInit {
  userForm!: FormGroup;

  constructor(private fb: FormBuilder) {}

  ngOnInit(): void {
    this.userForm = this.fb.group({
      name: ['', [Validators.required, Validators.minLength(3), Validators.maxLength(50)]],
      email: ['', [Validators.required, Validators.email]],
      age: [null, [Validators.required, Validators.min(18), Validators.max(100)]],
      role: ['user', Validators.required],
      password: ['', [Validators.required, Validators.minLength(8)]],
      confirmPassword: ['', Validators.required],
      phone: ['', Validators.pattern(/^[0-9]{10}$/)],
      website: ['', Validators.pattern(/^https?:\/\/.+/)]
    }, { validators: this.passwordMatchValidator });
  }

  passwordMatchValidator(group: FormGroup) {
    const pass = group.get('password')?.value;
    const confirm = group.get('confirmPassword')?.value;
    return pass === confirm ? null : { passwordMismatch: true };
  }

  get name() { return this.userForm.get('name'); }
  get email() { return this.userForm.get('email'); }

  onSubmit(): void {
    if (this.userForm.valid) {
      console.log(this.userForm.value);
    } else {
      this.userForm.markAllAsTouched();
    }
  }
}

4. FormArray — Dynamic / Repeatable Fields

Use when the user can add or remove rows (addresses, phone numbers, line items).

dynamic-form.component.ts 
import { Component, OnInit } from '@angular/core';
import { FormArray, FormBuilder, FormGroup, Validators } from '@angular/forms';

@Component({
  selector: 'app-dynamic-form',
  templateUrl: './dynamic-form.component.html'
})
export class DynamicFormComponent implements OnInit {
  form!: FormGroup;

  constructor(private fb: FormBuilder) {}

  ngOnInit(): void {
    this.form = this.fb.group({
      company: ['', Validators.required],
      contacts: this.fb.array([this.createContact()])
    });
  }

  get contacts(): FormArray {
    return this.form.get('contacts') as FormArray;
  }

  createContact(): FormGroup {
    return this.fb.group({
      name: ['', Validators.required],
      email: ['', [Validators.required, Validators.email]]
    });
  }

  addContact(): void {
    this.contacts.push(this.createContact());
  }

  removeContact(index: number): void {
    this.contacts.removeAt(index);
  }
}

7. Custom Validator

custom-validators.ts 
import { AbstractControl, ValidationErrors, ValidatorFn } from '@angular/forms';

export function noSpacesValidator(): ValidatorFn {
  return (control: AbstractControl): ValidationErrors | null => {
    const value = control.value as string;
    if (value && value.includes(' ')) {
      return { noSpaces: true };
    }
    return null;
  };
}

export function forbiddenNameValidator(forbidden: string): ValidatorFn {
  return (control: AbstractControl): ValidationErrors | null => {
    if (control.value?.toLowerCase() === forbidden.toLowerCase()) {
      return { forbiddenName: true };
    }
    return null;
  };
}

8. Async Validator (e.g. check username on server)

username-async.validator.ts 
import { AbstractControl, AsyncValidatorFn, ValidationErrors } from '@angular/forms';
import { Observable, of } from 'rxjs';
import { map, delay } from 'rxjs/operators';

export function usernameTakenValidator(checkFn: (name: string) => Observable<boolean>): AsyncValidatorFn {
  return (control: AbstractControl): Observable<ValidationErrors | null> => {
    if (!control.value) return of(null);
    return checkFn(control.value).pipe(
      map(taken => (taken ? { usernameTaken: true } : null))
    );
  };
}

4. Custom Pipe

Create a pipe when built-ins are not enough (truncate text, Celsius→Fahrenheit, highlight search term, etc.).

truncate.pipe.ts 
import { Pipe, PipeTransform } from '@angular/core';

@Pipe({ name: 'truncate' })
export class TruncatePipe implements PipeTransform {
  transform(value: string | null, limit = 20, trail = '...'): string {
    if (!value) return '';
    return value.length > limit ? value.substring(0, limit) + trail : value;
  }
}
celsius-to-fahrenheit.pipe.ts (Temperature Converter pattern) 
import { Pipe, PipeTransform } from '@angular/core';

@Pipe({ name: 'celsiusToFahrenheit' })
export class CelsiusToFahrenheitPipe implements PipeTransform {
  transform(celsius: number | null): string {
    if (celsius == null || isNaN(celsius)) return '';
    const fahrenheit = (celsius * 9) / 5 + 32;
    return fahrenheit.toFixed(2);
  }
}

import { Injectable } from '@angular/core';
import { BehaviorSubject, Observable } from 'rxjs';

export interface CartItem {
  id: number;
  name: string;
  qty: number;
}

@Injectable({ providedIn: 'root' })
export class CartService {
  private cartSubject = new BehaviorSubject<CartItem[]>([]);
  cart$ = this.cartSubject.asObservable();

  getCart(): CartItem[] {
    return this.cartSubject.value;
  }

  addToCart(item: CartItem): void {
    const current = this.cartSubject.value;
    const existing = current.find(c => c.id === item.id);
    if (existing) {
      existing.qty += item.qty;
      this.cartSubject.next([...current]);
    } else {
      this.cartSubject.next([...current, item]);
    }
  }

  clearCart(): void {
    this.cartSubject.next([]);
  }
}

What are Asynchronous operations?

An asynchronous operation starts now but finishes later — the program does not block and wait. The result arrives via a callback, Promise, or Observable when the work completes (HTTP call, timer, file read, user click).

Synchronous vs asynchronous

SynchronousAsynchronous
Line 2 runs only after line 1 finishesLine 2 can run while line 1 is still waiting
const x = a + b;http.get(...).subscribe(...)
Blocks the UI thread if slowUI stays responsive; result handled later

Common async operations in Angular

  • HTTP requests — HttpClient.get/post (Weather, Survey, Employee grid)
  • Timers — setTimeout, RxJS interval
  • User events — button click, form submit (handled asynchronously by Angular)
  • Route navigation — lazy-loaded modules load in background
Example — async HTTP in component 
// Synchronous — runs immediately
this.title = 'Weather App';

// Asynchronous — result comes later
this.weatherService.getWeather('London').subscribe(data => {
  this.weather = data;   // runs when server responds
});
Interview Answer: Async operations don't block the main thread. In Angular we handle them with Promises, Observables, or async/await so the UI stays responsive while waiting for APIs, timers, or events.

What is RxJS?

RxJS (Reactive Extensions for JavaScript) is a library for working with asynchronous data streams using the Observable pattern. Angular bundles RxJS — HttpClient, Router, and FormControl.valueChanges all use Observables.

Core RxJS concepts

ConceptDescription
ObservableStream that emits values over time
ObserverConsumer with next, error, complete handlers
SubscriptionLink between Observable and Observer; call unsubscribe() to stop
OperatorsFunctions to transform streams: map, filter, switchMap, etc.
SubjectObservable + Observer — multicast (e.g. BehaviorSubject for shared state)
Common operators in HackerRank / interviews 
import { map, filter, debounceTime, switchMap, catchError } from 'rxjs/operators';
import { of, throwError } from 'rxjs';

// map — transform each value
of(1, 2, 3).pipe(map(x => x * 10)).subscribe(v => console.log(v)); // 10, 20, 30

// filter — keep matching values
of(1, 2, 3, 4).pipe(filter(x => x % 2 === 0)).subscribe(v => console.log(v)); // 2, 4

// debounceTime — wait for pause (search box)
searchInput.valueChanges.pipe(
  debounceTime(300),
  switchMap(term => this.api.search(term))
).subscribe(results => this.results = results);

// catchError — handle HTTP failure
this.http.get('/api/data').pipe(
  catchError(err => { console.error(err); return of([]); })
).subscribe(data => this.items = data);
Interview Answer: RxJS is the reactive library Angular uses for async streams. It provides Observables, Subjects, and operators like map and switchMap to transform and combine async data cleanly.

What is Observable? How to implement Observable

An Observable is a lazy push stream: it produces values over time and notifies subscribers via next, error, and complete. In Angular, you consume Observables from HttpClient or create your own for custom async logic.

How to consume (subscribe)

From HttpClient (most common) 
this.productService.getAll().subscribe({
  next: products => this.products = products,
  error: err => this.error = 'Load failed',
  complete: () => this.loading = false
});
Template — async pipe (auto-unsubscribe)

<ul *ngIf="products$ | async as products">
  <li *ngFor="let p of products">{{ p.name }}</li>

1. new Observable() — custom logic 
import { Observable } from 'rxjs';

const counter$ = new Observable<number>(subscriber => {
  let count = 0;
  const id = setInterval(() => {
    subscriber.next(count++);
    if (count === 5) {
      subscriber.complete();
      clearInterval(id);
    }
  }, 1000);

  // Cleanup when unsubscribed
  return () => clearInterval(id);
});

counter$.subscribe(v => console.log(v)); // 0, 1, 2, 3, 4

import { of } from 'rxjs';

import { from } from 'rxjs';

What is the role of HttpClient in Angular?

HttpClient is Angular's built-in service for calling REST APIs. It returns Observables (not Promises), supports typed responses, query params, headers, and interceptors — used in almost every HackerRank Angular test that fetches data.

Role / responsibilities

  • Send HTTP requests (GET, POST, PUT, DELETE, PATCH)
  • Parse JSON responses into typed objects (get<T>())
  • Handle query parameters and request headers
  • Integrate with RxJS operators and interceptors (auth token, error handling)

Setup

  imports: [BrowserModule, HttpClientModule]
})

import { HttpClient, HttpParams, HttpHeaders } from '@angular/common/http';
import { Observable } from 'rxjs';

@Injectable({ providedIn: 'root' })
export class EmployeeService {
  private apiUrl = 'https://api.example.com/employees';

  constructor(private http: HttpClient) {}

  getAll(): Observable<Employee[]> {
    return this.http.get<Employee[]>(this.apiUrl);
  }

  getByPage(page: number, size: number): Observable<PagedResult<Employee>> {
    const params = new HttpParams()
      .set('pageNumber', page)
      .set('pageSize', size);
    return this.http.get<PagedResult<Employee>>(this.apiUrl, { params });
  }

  create(employee: Employee): Observable<Employee> {
    return this.http.post<Employee>(this.apiUrl, employee);
  }

  update(id: number, employee: Employee): Observable<Employee> {
    return this.http.put<Employee>(`${this.apiUrl}/${id}`, employee);
  }

  delete(id: number): Observable<void> {
    return this.http.delete<void>(`${this.apiUrl}/${id}`);
  }
}
